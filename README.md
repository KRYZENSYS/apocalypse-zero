# PROJECT APOCALYPSE ZERO

Android survival o'yini. Godot 4.x, GDScript, o'zbek lotin UI, to'liq offline.

## Holat: 2-bosqich (player va mobil boshqaruv) — sinalmagan
- Autoload: `GameManager`, `SceneManager`, `SettingsManager`
- Sahnalar: `main`, `main_menu`, `pause_menu`, `mobile_controls`, `player`, `test_world`
- Boshqaruv: sensorli (joystik, kamera, sakrash, egilish/emaklash, yugurish, amal, FPS/TPS) va klaviatura/sichqoncha (WASD, Space, Shift, C, Z, E, V, Esc)
- Player: state machine (Walk, Run, Crouch, Crawl, Air, Swim), FPS/TPS kamera

## Ishga tushirish
Godot 4.3+ da `project.godot` ni oching va Play (F5) bosing.

## Termux
`termux/` papkasidagi skriptlar va `docs/ANDROID_BUILD.md` ga qarang. Termux serveri YO'Q — o'yin mustaqil.

- Saqlash tizimi — placeholder (19-bosqich).

- Hech narsa Godot'da ishga tushirib sinalmagan.
